# AgentTrust — Beta Feedback

Eight questions, ~10 minutes. Be blunt — this is early beta and we'd
rather hear it now.

1. In your own words, what does AgentTrust do? (Tells us if the
   onboarding doc actually explained it.)

2. On a scale of 1–5, how easy was integration? What made it a 1 or a 5?

3. Where did you get stuck, if anywhere — which exact step?

4. Was looking an agent up by its endpoint URL (rather than by name or
   ID) a natural fit for how you'd actually use this?

5. Was the `trustDecision` (`recommended`/`confidence`/`reasons`)
   actually useful for a real decision, or just informational?

6. Would you actually use AgentTrust in a real agent or application
   today? Why or why not?

7. What would have to change before you'd use this in production?

8. If we built exactly ONE more thing next, what should it be?
